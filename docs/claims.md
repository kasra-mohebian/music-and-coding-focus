# Claim-to-evidence map

| Claim | Evidence | Appraisal |
|---|---|---|
| Remote developers describe perceived music benefits | M01, methods 3.2 and discussion 5–6 | Survey/self-report; no controlled code-performance effect |
| The programming EEG pilot demonstrated a music benefit | M04, sections V and VII | Not supported: music analyses were inconclusive |
| Mood effects imply better model quality | M07, institutional abstract | Not supported: no apparent music effect on model quality reported |
| Music recommender studies establish improved code quality | M09/M10, evaluation and limitations | Not supported: preference, behavioral proxies and interface measures differ from code quality |
| Preferred music can improve reported focus without a measured speed gain | M11, abstract/methods/results | Supported in this non-coding task; not a general equivalence claim |
| M11 and M12 are independent replications | M12, same-dataset statement | False; they share underlying data |
| M09 and M10 provide wholly independent samples | M10, introduction and evaluation | False; the journal article extends the conference study and adds evaluations |
| Faster music is always better than silence | M13, discussion limitations | Not supported: no silence baseline; only selected outcomes and music conditions |
| Listening before a perceptual task establishes a background-coding benefit | M14, procedures | Not supported: timing, population and outcome differ |
| The reading experiment proved all audio improved performance | M18, section 4.3 | Not supported: no significant overall condition difference in measured performance |
| General attention/learning findings transfer unchanged to coding | M08, M11–M18 | Not established; assess task/population differences |
| All 18 references are direct empirical programming experiments | Register classifications | False: mixed, indirect, context and metadata-only records are explicit |
| A universal BPM/volume or fixed lyrics penalty follows from this review | No comparable extracted evidence | Not asserted |

M02/M03 have primary bibliographic checks only; M07/M08/M16 have abstract-level checks; M15 also has author slides. Do not use those access labels as a substitute for full-text risk-of-bias appraisal. The [study appraisals](study-appraisals.md) document exactly what was inspected.
